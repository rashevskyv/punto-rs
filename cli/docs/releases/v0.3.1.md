Виправлення для Windows за першими відгуками з живої системи.

**Enter виправляє слово.** Набрали `ljlfq` і одразу `Enter` — punto-rs притримує `Enter`, виправляє слово на `додай` і лише потім натискає `Enter`. Повідомлення йде вже виправленим. `Shift+Enter`, `Ctrl+Enter` і `Enter` після пробілу не притримуються. Лише у Windows: у Linux evdev читається пасивно, і `Enter` уже в програмі.

**Швидше виправлення.** Паузи між натисканнями більше не розтягуються до такту системного таймера Windows (15,6 мс): punto-rs вмикає таймер з точністю 1 мс. Нову розкладку punto-rs помічає за 10 мс замість 50 мс.

**Українська мова інтерфейсу.** У Windows немає змінної `LANG`, тому `language=auto` завжди вибирав російську. Тепер `auto` вибирає українську, якщо інтерфейс Windows український або встановлено українську розкладку.
