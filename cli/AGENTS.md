# punto-rs CLI

`cli/` — Rust-крейт пользовательского демона исправления раскладки для Linux/Wayland и Windows. Он хранит скан-коды, а не текст, поэтому после системного переключения раскладки может стереть и переиграть те же физические клавиши.

## Поток данных

1. devices пассивно читает подходящие устройства evdev (в Windows - win/hook.rs, низкоуровневый хук) и посылает события в daemon; kwin и tray присылают активную программу и команды меню.
2. engine хранит буфер и состояние клавиш, определяет ручной хоткей или передаёт последнее слово детектору layout для автоисправления.
3. daemon перед коррекцией захватывает клавиатуры, а injector стирает буфер, посылает системную комбинацию смены раскладки и переигрывает скан-коды.
4. Ввод, накопленный во время захвата, переигрывается после коррекции; затем виртуальная клавиатура отпускает все синтетические клавиши.

## Модули

- `cli/src/main.rs` — аргументы, конфиг, выбор платформы.
- `cli/src/linux.rs` — запуск в Linux: блокировка экземпляра, потоки, сигналы.
- `cli/src/i18n.rs` — язык сообщений (ключ language), макрос tr! в `cli/src/main.rs`.
- `cli/src/lists.rs` — пользовательские списки слов-исключений и программ.
- `cli/src/tray.rs` — ядро значка в трее: состояние, меню, действия; `cli/src/tray/sni.rs` - StatusNotifierItem (ksni), `cli/src/tray/icon.rs` - картинка, `cli/src/tray/dialogs.rs` - диалоги.
- `cli/src/kwin.rs` — скрипт KWin, сообщающий класс активного окна.
- `cli/src/win/mod.rs` — Windows: хук (`cli/src/win/hook.rs`), SendInput (`cli/src/win/output.rs`), раскладка и окно переднего плана (`cli/src/win/watch.rs`), трей (`cli/src/win/tray.rs`), автозапуск (`cli/src/win/autostart.rs`), скан-коды (`cli/src/win/keymap.rs`).
- `cli/src/config.rs` — формат, значения по умолчанию и валидация конфигурации.
- `cli/src/daemon.rs` — цикл событий, захват, отмена, очередь и переигрывание ввода.
- `cli/src/devices.rs` — поиск устройств, evdev, EVIOCGRAB, ресинхронизация и фильтрация seat0.
- `cli/src/engine.rs` — буфер, состояние клавиш, ручные хоткеи и решение об автоисправлении.
- `cli/src/injector.rs` — виртуальная клавиатура uinput, стирание, смена раскладки и гарантированное освобождение клавиш.
- `cli/src/instance.rs` — безопасная файловая блокировка одного экземпляра.
- `cli/src/kde.rs` — состояние раскладки KDE через session D-Bus org.kde.keyboard.
- `cli/src/keys.rs` — скан-коды, их классификация и разбор комбинаций из конфига.
- `cli/src/layout.rs` — EN/RU/UK-детектор по триграммной модели и фильтрам Блума.
- `cli/src/session.rs` — проверка принадлежащей пользователю локальной незаблокированной сессии logind.
- `cli/src/state.rs` — ограниченный буфер скан-кодов и срез последнего слова.

## Тесты

- Внутримодульные тесты находятся рядом с кодом: в самих файлах и в `cli/src/engine/tests.rs`, `cli/src/layout/tests.rs`, `cli/src/daemon/tests.rs`.
- Интеграционные проверки CLI находятся в `cli/tests/cli.rs`.
- Размеченный набор детектора: `cli/tests/data/layout_cases.tsv`; правила модели и оценки: `cli/src/layout/AGENTS.md`.

## Инварианты

- Демон запускается без root как user-служба; доступ к /dev/input/* и /dev/uinput даёт группа input.
- Ложное автоисправление хуже пропуска: детектор должен быть консервативным.
- Коррекция выполняется только после EVIOCGRAB всех клавиатур. Ввод под захватом копится и переигрывается; события до захвата прерывают коррекцию.
- Виртуальная клавиатура после любой коррекции, отмены или ошибки не должна оставлять нажатых синтетических клавиш.
- Автоисправление включается только при паре раскладок us и ru или us и ua (вариант unicode/legacy) в KDE; активная раскладка приходит из session D-Bus org.kde.keyboard.
- Для раскладки используется только org.kde.keyboard. org.kde.KWin вызывается только из `cli/src/kwin.rs`: загрузка скрипта активного окна для программ-исключений.
- Платформенный код - только в `cli/src/linux.rs`, `cli/src/devices.rs`, `cli/src/injector.rs` (uinput), `cli/src/kde.rs`, `cli/src/kwin.rs`, `cli/src/session.rs`, `cli/src/instance.rs` и `cli/src/win/`; unsafe разрешён только в `cli/src/win/`. Проверяй и Windows-цель: `cargo clippy --target x86_64-pc-windows-gnu -- -D warnings`.

Проверяй изменения через `make full-check` из корня репозитория.
